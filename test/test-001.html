What Demo-ready means here

The product runs, does what it says, and is safe to demonstrate. It is not established as correct. Three things stand between this and a defensible claim:

  1. The back-test. Twenty decided use cases, predictions written before evaluating. This is the practitioner's own kill criterion and it has never been run.
  2. Exploratory testing — the VV-2(c) blocker. Structured tests confirm what was anticipated; exploration finds what was not.
  3. The LLM path has never run against the real API. Only ever a mocked SDK. Prompt quality, failure modes and cost are unknown.

The README currently describes the product as deployable. On this evidence that is true in the demo sense and not in the evidential sense.
