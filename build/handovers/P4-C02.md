established); `jurisdictions` genuinely IS a real `PolicyFile` field and is
sourced from the loaded policy for real. Documented inline in
`StructuredForm.tsx`, not just in the build prompt.

## Deviations from Spec

1. **§5.2 field-name drift** (see above) — resolved via
   `canonical-vocabulary.ts`, not a per-policy field.
2. **BC-P4C02-03: no `usePolicy()` hook built.** The spec (§5.1) names a
   `usePolicy()` hook exposing `hasApiKey`. `IntakeFlow.tsx` already has
   `getApiKey()` (from `client.ts`) available directly — introducing a new
   hook for a single boolean check was judged unnecessary indirection.
   Documented inline; can be added later if `hasApiKey` needs to be
   consumed by more than one component.
3. **The constructed graph includes edges**, unlike the build prompt's
   "no edges" expectation — a positive deviation, not a defect (see Code
   Review Findings).
