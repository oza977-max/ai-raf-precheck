## Deviations from Spec (found by the owner-side live walkthrough, fixed in R16-W)
This chunk's own commit message flags that a walkthrough found issues
"fixed in the next commit." Specific to this chunk (D1):
1. **The knowledge-lens panel rendered outside the collapsed reviewer
   section** — `IntakeFlow` rendered `KnowledgeLensPanel` after
   `VerdictDisplay`, so "curated by project maintainer (2LoD practitioner)"
   text sat on a newcomer's first screen (VD-9 requires everything beyond
   the nine first-screen items to be collapsed).
2. **The "also covers" note broke on clause-shaped review names** — a
   safeguard covering two reviews printed two separate notes, and the
   template read ungrammatically against a clause-shaped `plain_name`
   ("This also covers the supplier is assessed — one piece of work.").
3. **Firm-level evidence claimed "in place" for tools it did not cover** —
   `CTRL-ENC-01`'s stored evidence ("Platform allow-list pins TLS 1.3…") is
   about the firm's own allow-listed platforms, but every verdict that
   tripped the control — including a personal ChatGPT account the firm has
   no contract with — showed it as already satisfied.

All three were found on the running app during the same owner-side
walkthrough and fixed in `4a52661` (R16-W) — W-5, W-6 and W-7 respectively.
See `R16-W.md`, which also records the RG-9 requirements amendment item 3
produced.
