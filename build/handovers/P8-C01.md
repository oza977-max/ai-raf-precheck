## Retrospective
The review loop earned its keep. Pass 1's second finding — that inferring 'selected' from array length would let old drafts through the new gate — was a hole I opened while fixing the original defect, and it is exactly the RF-4 pattern this project's calibration warns about: a fix that displaces the defect rather than removing it. Neither the test suite nor the type checker would have caught it; only someone reading for that class did.

The upstream fixes are worth noting for their shape. Six tests broke, and every one broke because it had been asserting the old, defective behaviour. That is the healthy signal — a change that closes a real gate should break the tests that walked through it.
