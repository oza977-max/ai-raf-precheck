### `src/store/policy.ts` — real loader (replaces the P1-C01 stub)
```typescript
export function loadPolicy(yaml: string): PolicyValidationResult
```
Implementation:
1. Parse `yaml` with `js-yaml`'s `load()`. Catch parse errors → return
   `{ valid: false, errors: [{ kind: 'policy-invalid', field: 'yaml', reason: '<parse error message>' }], warnings: [] }`.
2. Validate with a Zod schema matching the `PolicyFile` interface above. On Zod failure, map each
   Zod issue to a `PolicyValidationError` naming the exact field path (`err.path.join('.')`).
3. Run the explicit checks from `policy-schema.md §6` (Zod schema presence checks alone are not
   enough — these are additional semantic checks):
   - `version` present and non-empty
   - `translation_attestation` block present
   - `hard_lines` array present (may be empty)
   - `controls` array **non-empty** (`policy-invalid: controls section is empty — at least one control required`)
   - `tracks` array has ≥1 rule
   - `tiers` array has ≥1 rule
   - `tier_workflow` maps all four tiers (Critical/High/Medium/Low)
   - `safety_margin` between 0.0 and 1.0
4. Validate every condition value in `hard_lines`, `tracks[].conditions`, `tiers[].triggers`, and
   `invariants[].condition` against the §3.0 canonical vocabulary (import the enums from
   `src/engine/types.ts` — do not redefine them here). A value outside the enum →
   `pack-invalid` or `policy-invalid` (use `policy-invalid` for main-file conditions) naming the
   field and the invalid value.
5. Condition language operators: only `gte`, `lte`, `in`, `not_in`, and bare equality are valid
   operator keys inside a condition object (per `policy-schema.md §8` ADR-002). Any other operator
   key → validation error.
6. Return `{ valid: true, policy, warnings }` on success. `warnings` includes a non-blocking note
   if `firm_name` is still `"[FIRM]"` (per §6: "warn but don't block").

## Framework Reference

**`js-yaml` load:**
```typescript
import { load } from 'js-yaml';
const parsed: unknown = load(yamlString);  // throws on malformed YAML
```

**Zod schema pattern (schema IS the validator AND the type source, per cross-cutting.md §4):**
```typescript
import { z } from 'zod';

const ConditionOperatorSchema = z.union([
  z.object({ gte: z.number() }),
  z.object({ lte: z.number() }),
  z.object({ in: z.array(z.string()) }),
  z.object({ not_in: z.array(z.string()) }),
  z.string(), z.number(), z.boolean(),  // bare equality
]);

const HardLineSchema = z.object({
  id: z.string(),
  description: z.string(),
  condition: z.record(z.string(), z.unknown()),
  reason: z.string(),
  regulatory_basis: z.string(),
});

const PolicyFileSchema = z.object({
  version: z.string().min(1),
  policy_id: z.string(),
  firm_name: z.string(),
  translation_attestation: z.object({
    attested_by: z.string(),
    role: z.string(),
    date: z.string(),
    raf_version_checked: z.string(),
  }),
  hard_lines: z.array(HardLineSchema),
  controls: z.array(z.unknown()).min(1),  // non-empty per §6
  tracks: z.array(z.unknown()).min(1),
  tiers: z.array(z.unknown()).min(1),
  tier_workflow: z.object({
    Critical: z.string(), High: z.string(), Medium: z.string(), Low: z.string(),
  }),
  safety_margin: z.number().min(0).max(1),
  // ... remaining fields
});

const result = PolicyFileSchema.safeParse(parsed);
if (!result.success) {
  const errors = result.error.issues.map(issue => ({
    kind: 'policy-invalid' as const,
    field: issue.path.join('.'),
    reason: issue.message,
  }));
  return { valid: false, errors, warnings: [] };
}
```
